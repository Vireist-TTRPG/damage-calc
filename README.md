# Irreality · Калькулятор огнестрельного урона

Статический сайт-калькулятор для сеттингонезависимой НРИ **Irreality**.
Считает урон огнестрела, поглощение бронепластиной, износ Целостности и показывает каждое вычисление.
Правила и содержимое сеттингов подключаются **модулями** — JSON-манифестами.

## Интерфейс v3 «Пульт»

- **Липкий пульт под шапкой.** Все ходовые параметры — успехи атаки и защиты, Рейтинг,
  патрон, броня (носитель + пластина одним селектом), Целостность, а в полном режиме ещё
  режим, дистанция, тип оружия и укрытие — всегда на экране. Никакой прокрутки ради настроек.
  Кнопки «Бросить» и «Обстрел в журнал» — тут же: полный цикл обстрела без скролла.
- **Результат слева, детали справа.** Вкладки «Патрон / Броня / Обстрел / Правила / Пул»
  показывают живые значения прямо на ярлычках; содержимое каждой вкладки короткое.
- **Карманный док на мобильных.** Атака и Защита steppers’ами закреплены снизу экрана,
  чип результата прокручивает к расчёту.
- **Два режима.** «Простой» — шесть параметров на пульте и две вкладки деталей.
  «Полный» — десять параметров, пять вкладок, справочник и формат модуля.
- **Светлая и тёмная темы**, выбор при первом входе и переключатель в шапке.
- Подписи чипов патронов и режимов — код отдельной строкой, полное название под ней с отступом.
- Типы оружия — без калибров: калибр и баллистика живут в патроне.

## Публикация на GitHub Pages

1. Закоммитьте содержимое проекта в корень репозитория.
2. `Settings → Pages → Source: Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Откройте выданный адрес. Всё считается локально в браузере, бэкенда нет.

Локально `index.html` можно открыть двойным кликом — сработает резерв на встроенных копиях модулей.
Чтобы читать реальные файлы, поднимите статический сервер:

```bash
python -m http.server 8080
