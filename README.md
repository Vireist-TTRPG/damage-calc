# Irreality · Калькулятор огнестрельного урона

Статический сайт-калькулятор для сеттингонезависимой НРИ **Irreality**.
Считает урон огнестрела, поглощение бронепластиной, износ Целостности и показывает каждое вычисление.
Правила и содержимое сеттингов подключаются **модулями** — JSON-манифестами.

## Что нового в v2

- **Два интерфейса.** «Простой» — пять параметров и результат, для новичка за столом. «Полный» — конструктор пулов, дистанции, режимы, укрытия, правила, справочник и формат модуля. Переключатель в шапке и на экране первого входа; выбор запоминается.
- **Светлая и тёмная темы.** Полный набор токенов: бумага и оксблад против графита и кармина. Переключатель в шапке, выбор на первом входе, корректная печать в обеих.
- **Конструктор пула из любых атрибутов и навыков.** Строки добавляются и удаляются, имя выбирается из словаря ядра и модулей или вводится вручную (в том числе отрицательный модификатор). Пресеты, автоподсчёт, бросок d10 с подсветкой успехов, критов и единиц.
- **Типы оружия без калибров.** Калибр и баллистика живут в патроне, а не в назстве класса.
- **Слитные подписи выбранных пунктов.** Выбранный патрон или режим показывает код и полное название одним текстом: `FMJОболочечный`, `ОЧОчередь`.

## Публикация на GitHub Pages

1. Закоммитьте содержимое проекта в корень репозитория.
2. `Settings → Pages → Source: Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Откройте выданный адрес. Всё считается локально в браузере, бэкенда нет.

Локально `index.html` можно открыть двойным кликом — сработает резерв на встроенных копиях модулей.
Чтобы читать реальные файлы, поднимите статический сервер:

```bash
python -m http.server 8080
