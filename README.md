# Irreality · Калькулятор огнестрельного урона

Статический сайт-калькулятор для сеттингонезависимой НРИ **Irreality**.
Считает урон огнестрела, поглощение бронепластиной, износ Целостности и показывает каждое вычисление.
Правила и содержимое сеттингов подключаются **модулями** — JSON-манифестами.

  Атрибуты: Сила, Ловкость, Выносливость · Влияние, Эмпатия, Сила воли · Восприятие, Смекалка, Эрудиция.
  Навыки: Атлетика, Реакция, Меткость, Вождение, Ремесло, Скрытность, Фехтование ·
  Запугивание, Исполнение, Убеждение, Обман, Проницательность, Обращение с животными, Этикет ·
  Технические науки, Гуманитарные науки, Медицина, Наблюдательность, Оккультизм, Анализ, Выживание.
  Модули могут добавлять свои группы (`{group, names}`) или плоские строки — оба формата работают.
- **Читаемость.** Все мелкие шрифты подняты: минимум ~10px для подписей, 12–13px для текста.
- **Журнал без наложений.** Числа обстрела живут в собственном контейнере, кнопки управления —
  в своей колонке с авто-шириной: меню больше не перекрывает «ОСТАТОК» после износа.
  На мобильных — две строки: бейджи сверху, числа и кнопки снизу.
- **Справочник без пустот.** Карточки уложены кладкой (CSS columns): каждая держит свою высоту,
  короткая «Стальная» не растягивается под «Саркофаг». Табличный вид сохраняется.
  Кнопки пластин во вкладке «Броня» прижимают статистику к нижнему краю.

## Интерфейс «Пульт»

- Липкая панель под шапкой: успехи атаки/защиты, Рейтинг, патрон, броня, Целостность;
  в полном режиме — режим, дистанция, тип оружия, укрытие. «Бросить» и «Обстрел в журнал» — там же.
- Результат слева, детали-вкладки справа («Патрон / Броня / Обстрел / Правила / Пул»)
  с живыми значениями на ярлычках.
- Карманный док на мобильных: атака и защита закреплены снизу.
- Простой и полный режимы, светлая и тёмная темы, выбор при первом входе.

## Публикация на GitHub Pages

1. Закоммитьте проект в корень репозитория.
2. `Settings → Pages → Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Всё считается локально в браузере. Локально без сервера работает резерв встроенных модулей;
   для чтения файлов: `python -m http.server 8080`.

## Как считается обстрел

1. `Разница = успехи атаки − успехи защиты`. При Разнице ≤ 0 — промах.
2. `Урон = Рейтинг + Разница + модификаторы патрона и режима`. Огнестрел ядра — Усугублённый.
3. `Защита = защита пластины − поломка + первая пуля − пробитие (+ укрытие, если правило включено)`.
4. `Поглощено = min(урон, Защита)`; остаток → в здоровье как Усугублённый.
5. `Износ = Поглощено ÷ делитель (округление пластины)`; дробь и плазма не делятся.
6. Целостность списывается **один раз за обстрел**. При 0 пластина ломается (−breakPenalty к Защите).
