    Журнал

    Целостность переносится между обстрелами. Порядок можно менять перетаскиванием — серия пересчитывается целиком.

    Серия пуста Настройте обстрел слева и нажмите «Зафиксировать обстрел» — запись появится здесь, а Целостность брони перейдёт к следующему выстрелу.

    РАСШИРЕНИЕ СИСТЕМЫ

    Формат модуля

    Модуль — один JSON-манифест в папке /modules. Добавьте файл, впишите его в реестр — он появится в конфигурации при входе.

    1 · Структура проекта

    modules/
├── index.json            ← реестр загрузки
├── irreality-core.json   ← ядро (всегда включено)
├── isotope-tier.json     ← модуль сеттинга
└── my-setting.json       ← ваш новый модуль

    2 · Реестр

    {
  "schema": "irreality.module-registry/1",
  "modules": [
    { "id": "irreality-core", "file": "irreality-core.json", "required": true },
    { "id": "isotope-tier",   "file": "isotope-tier.json" },
    { "id": "my-setting",     "file": "my-setting.json" }
  ]
}

    3 · Поля манифеста

    id, namespaceУникальные. Пространство имён даёт идентификаторы вида iso:sarcophagus и защищает от конфликтов.
    kindcore — ядро (нельзя выключить), module — обычный модуль.
    requiresМассив id обязательных зависимостей. Без них модуль не включится.
    damageTypesТипы урона: id, label, short, tone. Формат универсален — можно ввести свои типы.
    platesdefense, integrity, rounding (floor/round/ceil), breakPenalty, firstShot, passive, effects.
    carriersНосители: plates — список допустимых пластин, passive.mods — штрафы к пулу.
    carrierExtensionsРасширение чужого носителя: target: "core:heavy", addPlates: ["sarcophagus"].
    ammodamageType, damageBonus, damageVsArmor, attackDice, armorPierce, ignoreWearDivision, fixedDamage, surfaceBypass, tags, effects.
    weaponsНеобязательно: rating, weaponClass — стволы появятся в селекторе и справочнике.
    weaponClasses, fireModes, coversТаблицы дистанций, режимы и укрытия. Ядро задаёт базовые, модуль может добавить свои.
    rulesНастраиваемые правила: toggle, number, select + default, dependsOn. Появляются в блоке «Правила».

    4 · Эффекты и условия

    reduceDamagedamageType, amount, min, rule, minRule — снижение урона определенного типа.
    extraWearamount / rule — дополнительный износ Целостности за обстрел.
    zeroIntegritytarget — обнуление Целостности указанного слоя (нарративный флаг).
    notetext — предупреждение мастеру в списке эффектов.
    whenУсловия: ammoTag, ammoId, damageType, armored, broken. Пустое — всегда.
    ruleСсылка на значение правила модуля: "rule": "iso:sacrificialWear".

    Порядок загрузки задаётся перетаскиванием в конфигурации: нижние модули применяются поверх верхних. Неизвестные типы эффектов не ломают расчёт — они попадают в отчёт о валидации.

    КОНФИГУРАЦИЯ · ПЕРЕД ВХОДОМ

    Модули Irreality

    Ядро системы загружается всегда. Подключите модули сеттингов — их пластины, патроны, стволы и правила появятся в калькуляторе и справочнике. Порядок загрузки меняется перетаскиванием.

    Как добавить свой модуль

    1. Скачайте шаблон манифеста.
    2. Положите файл в папку /modules.
    3. Добавьте запись в modules/index.json.
    4. Обновите страницу — модуль появится здесь.
    Локальная проверка хранится только в этом браузере и не попадает в репозиторий.

    Отчёт загрузки

      Правила загрузки

      • Ядро нельзя выключить и оно всегда первое.
      • Зависимости обязательны: модуль не включится без них.
      • Namespace изолирует идентификаторы: core:kevlar и iso:sarcophagus.
      • Порядок: нижние модули расширяют и переопределяют верхние.
