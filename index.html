    Журнал

    Целостность переносится между обстрелами. В полном режиме порядок меняется перетаскиванием, и вся серия пересчитывается целиком.

    Серия пуста Настройте обстрел на пульте и нажмите «Обстрел в журнал» — запись появится здесь, а Целостность брони перейдёт к следующему выстрелу.

    РАСШИРЕНИЕ СИСТЕМЫ

    Формат модуля

    Модуль — один JSON-манифест в папке /modules. Добавьте файл, впишите его в реестр — он появится в конфигурации при входе.

    1 · Структура проекта

    modules/
├── index.json            ← реестр загрузки
├── irreality-core.json   ← ядро (всегда включено)
├── isotope-tier.json     ← модуль сеттинга
└── my-setting.json       ← ваш новый модуль

    2 · Реестр

    {
  "schema": "irreality.module-registry/1",
  "modules": [
    { "id": "irreality-core", "file": "irreality-core.json", "required": true },
    { "id": "isotope-tier",   "file": "isotope-tier.json" },
    { "id": "my-setting",     "file": "my-setting.json" }
  ]
}

    3 · Поля манифеста

    id, namespaceУникальные. Пространство имён даёт идентификаторы вида iso:sarcophagus и защищает от конфликтов.
    kindcore — ядро (нельзя выключить), module — обычный модуль.
    requiresМассив id обязательных зависимостей. Без них модуль не включится.
    attributes, skillsСловари конструктора пула: группы {group, names} или строки.
    damageTypesТипы урона: id, label, short, tone.
    platesdefense, integrity, rounding, breakPenalty, firstShot, passive, effects.
    carriers, carrierExtensionsНосители и расширение чужих носителей: target, addPlates.
    ammodamageType, damageBonus, damageVsArmor, attackDice, armorPierce, ignoreWearDivision, fixedDamage, surfaceBypass, tags, effects.
    weapons, weaponClasses, fireModes, coversБаза стволов, дистанции, режимы, укрытия. Тип оружия — без калибра.
    rulesНастраиваемые правила: toggle, number, select + default, dependsOn.

    4 · Эффекты и условия

    reduceDamagedamageType, amount, min, rule, minRule.
    extraWearamount / rule — дополнительный износ за обстрел.
    zeroIntegritytarget — обнуление Целостности указанного слоя.
    notetext — предупреждение мастеру.
    whenУсловия: ammoTag, ammoId, armored, broken.
    ruleСсылка на значение правила: "rule": "iso:sacrificialWear".

    Порядок загрузки задаётся перетаскиванием: нижние модули применяются поверх верхних. Неизвестные типы эффектов не ломают расчёт — они попадают в отчёт о валидации.

    КОНФИГУРАЦИЯ · ПЕРЕД ВХОДОМ

    Модули Irreality

    Ядро системы загружается всегда. Подключите модули сеттингов — их пластины, патроны, стволы и правила появятся на пульте, в деталях и справочнике. Порядок загрузки меняется перетаскиванием.

    Интерфейспереключается в шапке в любой момент
    Темаприбор одинаково точен в обеих

    Как добавить свой модуль

    1. Скачайте шаблон манифеста.
    2. Положите файл в папку /modules.
    3. Добавьте запись в modules/index.json.
    4. Обновите страницу — модуль появится здесь.
    Локальная проверка хранится только в этом браузере и не попадает в репозиторий.

    Отчёт загрузки

      Правила загрузки

      • Ядро нельзя выключить, оно всегда первое.
      • Зависимости обязательны: модуль не включится без них.
      • Namespace изолирует идентификаторы: core:kevlar и iso:sarcophagus.
      • Порядок: нижние модули расширяют и переопределяют верхние.
